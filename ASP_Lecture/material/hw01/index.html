3. Numpy and Plotly: Collatz Conjecture

Collatz Conjecture

Consider the following sequence \(u = (u_i)\) of natural numbers given by

\[ \begin{equation} u_{i+1} = \begin{cases} u_i /2 & \text{if }u_i \text{ is even}\\ 3u_i + 1 & \text{if }u_i \text{ is odd} \end{cases} \end{equation} \]

starting with a number \(u_0 = n \in \mathbb{N}\).

The Collatz Conjecture states that whatever the starting integer \(n \in \mathbb{N}\), the sequence ultimately reaches \(1\). The conjecture is still an open problem; some partial answers in this direction were given by Terence Tao in 2019.

For \(n \in \mathbb{N}\), denote by

\[ \tau(n) : = \inf\{i \colon u_i = 1\} \]

which represents the first time where the sequence starting from \(n\) reaches \(1\). If this sequence never reaches \(1\) starting with \(n\), then \(\tau(n) = \infty\). Collatz conjecture states that \(\tau(n)<\infty\) for every \(n\).

There is strong confidence that this conjecture is true, and empirically, it holds for every natural number smaller than \(2^{68}\)

3.1 Using the control flow while, given an integer \(n\) write a function that returns a numpy array \((u_0, u_1, \ldots, u_{\tau(n)})\). Mathematically, also write down the domain and codomain of this function.

3.2 Using plotly, provide a function where given a numpy array \(x = (n_0, \ldots, n_{d-1})\) it plots \(d\) paths \((u_0, \ldots, u_{\tau(n_k)})\) where \(u_0 = n_k\) for \(k=0, \ldots, d-1\).

3.3 Write a third function where, given a numpy array \(x = (1, \ldots, d)\) it returns the array \((\tau(1), \ldots, \tau(d))\).

3.4 Using the bar plotting functionality (fig.add_bar(...)) of plotly, write a function that plots the histogram of the previous function, that is \((l_1, l_2, \ldots)\) where

\[ \begin{equation} l_k = \text{Cardinality}\{n\colon \tau(n) = k, \quad 0\leq n \leq N\} \end{equation} \]

for (depending on the performance of your computer) \(N=1000, 10000, 100000\).
